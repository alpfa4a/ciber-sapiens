Cuadernos de Trinchera

Notas de campo, procedimientos de administración de sistemas y guías prácticas para el despliegue de infraestructuras ligeras y soberanas.

Este directorio se actualiza de forma modular conforme se consolidan nuevas herramientas y soluciones en el taller.

[Actualización: 2026-10]

01. Aislamiento de Proyectos en Python 3 mediante venv

Guía para sortear restricciones de paquetes administrados externamente (PEP 668) en distribuciones Linux modernas sin comprometer el sistema base.

[Actualización: 2026-11]

02. Escape del alquiler digital: Despliegue soberano en GitHub Pages

Guía práctica de trinchera para estructurar, versionar con Git y publicar un sitio web estático libre de costes y pasarelas de pago.

[Actualización: 2026-11]

03. Inferencia de Entropía en Python (SIEsP) y Control de Hybris

Medición de incertidumbre en el código mediante análisis sintáctico, complejidad ciclomática y reflexividad ética con hybris_control()

[Actualización: 2026-11]

04. Desarrollo Empírico de SIEsP: De la Incertidumbre en Crudo a la Entropía 1.04

Este cuaderno documenta el proceso científico real de calibración del prototipo dentro de un entorno virtual aislado (venv), analizando los errores sintácticos de compatibilidad de API y mostrando la drástica reducción del índice de entropía hasta alcanzar un estado de orden de 1.04.
