Aislamiento de Proyectos en Python 3 mediante venv

En distribuciones Linux modernas basadas en Debian/Ubuntu, la ejecución directa de pip install a nivel global se encuentra restringida por diseño (PEP 668). Esto evita que paquetes externos sobrescriban las librerías nativas gestionadas por el administrador de paquetes del sistema operativo (apt).

La vía limpia, elegante y soberana para instalar dependencias sin alterar el sistema base es el uso de entornos virtuales propios.

1. Preparación del paquete base

Comprueba que dispones del módulo de entornos virtuales de Python instalado en el sistema:

sudo apt update
sudo apt install python3-venv python3-full

2. Creación del entorno aislado

Sitúate en el directorio raíz de tu proyecto y genera la carpeta del entorno virtual (se suele denominar .venv u env):

cd /ruta/a/tu/proyecto
python3 -m venv .venv

3. Activación y uso

Para trabajar dentro del entorno aislado, ejecuta el script de activación en la shell actual:

source .venv/bin/activate

Verás que la línea de comandos antepone el prefijo (.venv). A partir de este momento, cualquier llamada a pip instalará las librerías exclusivamente dentro de la carpeta local de tu proyecto:

pip install nombre_del_paquete

4. Desactivación

Una vez concluida la sesión de trabajo, puedes salir del entorno virtual simplemente invocando:

deactivate
📌 Nota de buena práctica para repositorios Git: Si utilizas control de versiones, recuerda añadir siempre la carpeta del entorno virtual a tu archivo .gitignore para evitar subir binarios o dependencias compiladas al servidor: 
echo ".venv/" >> .gitignore
